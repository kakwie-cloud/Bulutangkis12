Identitas Peserta Didik

Materi Strategi Penyerangan & Taktik Pertahanan

Pelajari konsep analisis gerakan, variasi pukulan, dan posisi lapangan.

1. Teknik Smash

Serangan Tajam

Pengertian: Pukulan overhead yang menukik tajam dan kencang ke arah lapangan lawan.

Variasi Smash:

🔹 Smash Lurus: Mengarah sejajar garis pinggir lapangan untuk menekan reaksi lawan.

🔹 Smash Silang (Cross-court): Memindahkan arah bola ke area kosong lawan secara mendadak.

🔹 Jump Smash: Dikelakukan sambil melompat untuk menambah sudut kencang dan sudut ke bawah.

Kapan Digunakan: Saat mendapat shuttlecock lambung tinggi di area tengah atau belakang lawan.

2. Teknik Drop Shot

Serangan Kecohan

Pengertian: Pukulan seolah smash namun shuttlecock jatuh secara perlahan dekat jaring (net).

Variasi Drop Shot:

🔸 Slow Drop Shot: Shuttlecock meluncur halus menyusur net untuk memancing lawan maju.

🔸 Fast Drop Shot: Menukik lebih cepat untuk mengejutkan lawan yang mati langkah.

Fungsi Taktis: Mengubah tempo permainan dan menguras fisik lawan yang bertahan di belakang.

3. Pukulan Netting

Kontrol Depan

Pengertian: Pukulan pendek yang dilakukan di dekat net agar shuttlecock jatuh setipis mungkin di area lawan.

Variasi Netting:

🟢 Netting Tipis: Shuttlecock bergulir hampir menyentuh pita atas net.

🟢 Netting Silang: Mengarahkan shuttlecock ke sudut net secara menyilang.

Tujuan Utama: Memaksa lawan melakukan *underhand lob* tinggi sehingga mudah di-smash.

4. Pertahanan Tunggal

Single Defense

Fokus pada cakupan seluruh area lapangan oleh satu pemain dengan kembali ke *base position* (posisi tengah).

🔹 Posisi raket selalu siap di depan dada.

🔹 Mengembalikan smash keras ke area kosong yang jauh dari jangkauan lawan.

🔹 Mengubah pertahanan pasif menjadi serangan balik lewat drive kencang.

5. Taktik Pertahanan Permainan Ganda

Pola Berdampingan vs Depan-Belakang
Pola Berdampingan (Side-by-Side):

Digunakan saat BERTAHAN dari serangan smash lawan. Masing-masing pemain bertanggung jawab atas separuh lapangan kiri dan kanan.

Pola Depan-Belakang (Front-Back):

Digunakan saat MENYERANG. Satu pemain menguasai area jaring/depan, sementara pemukul utama berada di area belakang.

Kode Google Apps Script (`Code.gs`)

Salin seluruh kode di bawah ini ke dalam Google Apps Script (Code.gs) di Google Spreadsheet Anda untuk mengaktifkan penyimpanan data otomatis. 

function doPost(e) {
  try {
    var contents = JSON.parse(e.postData.contents);
    var action = contents.action;
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    
    if (action === "saveEvaluation") {
      var sheet = getOrCreateSheet(ss, "HASIL EVALUASI");
      sheet.appendRow([
        new Date(),
        contents.nama,
        contents.kelas,
        contents.skor,
        contents.benar,
        contents.waktu,
        contents.status
      ]);
    } else if (action === "saveAnalysis") {
      var sheet = getOrCreateSheet(ss, "ANALISIS VIDEO");
      sheet.appendRow([
        new Date(),
        contents.nama,
        contents.kelas,
        contents.jenisSerangan,
        contents.alasan,
        contents.kelemahan,
        contents.rekomendasi
      ]);
    } else if (action === "saveReflection") {
      var sheet = getOrCreateSheet(ss, "REFLEKSI");
      sheet.appendRow([
        new Date(),
        contents.nama,
        contents.kelas,
        contents.q1,
        contents.q2,
        contents.q3,
        contents.q4
      ]);
    }
    
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function getOrCreateSheet(ss, name) {
  var sheet = ss.getSheetByName(name);
  if (!sheet) {
    sheet = ss.insertSheet(name);
  }
  return sheet;
}
